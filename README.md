# 🎥 评论雷达 · Comment Radar

> TikTok 直播间评论采集与智能分析系统 —— 产品经理演示 Demo

一个面向 **TikTok 直播间运营场景** 的评论采集与智能分析工具。帮助主播实时捕捉高转化意向评论，帮助运营/老板复盘全公司直播间的产品舆论风向。

---

## ✨ 功能概览

### 四大模块

| 模块 | 说明 |
|------|------|
| 📊 **总览** | 直播间列表（直播中 / 已结束）、顶部统计卡（累计用户数 / 累计评论 / 实时监控数）、全网评论风向 |
| 🔴 **实时监控** | 直播中评论区实时滚动刷新，AI 自动标记「需回复」评论（红色角标） |
| 📈 **数据分析** | 全网关键词词云、意向分类占比、整体舆论情绪、各直播间舆论对比 |
| ⚙️ **系统设置** | AI 需回复标签开关、采集频率、多语言支持、推送设置 |

### 核心技术点

- **AI 需回复标记**：多语言评论（越南 / 泰 / 印尼 / 英）→ AI 智能分类 → 标记高意向评论
- **累计用户数（去重 UV）**：按用户 ID 去重统计，反映真实客群规模，而非评论频次
- **复盘分析**：直播结束后自动生成词云、意向分布、情绪占比、问题集中点
